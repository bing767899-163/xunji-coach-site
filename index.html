Xunji AI Coach

A personal training assistant that turns the developer’s workout records and training templates into a practical plan for the day.

How it works

A Python program running on GitHub Actions reads the developer’s training records and templates from Xunji. It applies fixed rules to prepare training suggestions and uses the Gmail API to email the plan to the developer’s own account.

Personal use

The project is for the developer’s own use. Public registration is unavailable. Training suggestions are rule based, and the program currently uses no paid large language model services.

Learn how the project handles training records and Gmail access in the Privacy Policy.
