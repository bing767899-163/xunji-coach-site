Xunji AI Coach

Privacy Policy

This policy describes how the developer’s personal training assistant handles Xunji training data and Google account data. The project is for the developer’s own use and has no public registration.

Training records and templates

The Python program uses the Xunji API in read-only mode. It reads training dates, workout and exercise information, set counts, weights, repetitions, completion status, and timing or effort fields when available. It reads training templates for planned exercises and set targets. Fixed rules use this information to generate training suggestions and a plan for the developer.

Gmail access and delivery

The program uses Google OAuth 2.0 with the gmail.compose scope. It checks the authorized Gmail account’s email address against the configured recipient and sends training plans only to that account. The email can contain the developer’s training information.

Before sending, the program lists drafts and checks their Message-ID headers to detect an earlier attempt. It creates a reservation draft with a deterministic Message-ID and a short operational message. That draft contains no training plan. The program retains it to help prevent duplicate delivery, including when a send attempt has an uncertain result.

Service providers

  • Xunji supplies the developer’s training records and templates through its API.
  • Google provides OAuth authorization, Gmail draft access, and mail delivery.
  • GitHub runs the Python program through GitHub Actions and provides the intended hosting for this static site through GitHub Pages.

The project uses data for its personal training workflow. It does not sell personal data or provide it to third-party advertisers. These pages contain no analytics scripts or registration forms.

Credentials and retention

OAuth credentials are stored in a local directory excluded from Git and in GitHub Actions Secrets. They are kept separate from the public website. Workflow output is designed to report status without exposing credentials or full training records.

Local training exports and previews can remain on the developer’s computer until the developer removes them. Sent plans and reservation drafts can remain in Gmail until they are removed under the account’s settings or Google’s retention practices. GitHub manages retention for its workflow records according to repository and platform settings. The project does not apply a fixed deletion period across these services.

Revoking Google access

To stop future Gmail access, open your Google Account connections, select the OAuth app used by Xunji AI Coach, and remove its access. Revocation does not itself remove existing Gmail messages, drafts, local exports, or workflow records.
